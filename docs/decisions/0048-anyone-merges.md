# 0048: Anyone can merge to main; Alex's agent organizes

- Date: 2026-11-14
- Status: accepted
- Source: issue #6
- Agreed by: Alex

Anyone may push or merge to main, but only when their human asks for that specific action. Branches, PRs, issues and comments need no permission. Alex's agent stays the master agent and organizes the work: issues, milestones, decisions and keeping the docs in sync. Supersedes 0026 and the merge rules in 0044 and 0047.

## Alternatives

| Option | Critique |
| --- | --- |
| **Anyone merges when their human asks; one agent organizes** | No one waits on Alex while he's at the robot; the human OK keeps main from changing by accident; one place still owns issues and docs |
| Only the master agent merges (0026) | Every PR waits on Alex, who is at the robot most of Saturday |
| Anyone merges, no human OK | Fastest, but an agent could change main on its own |

## Reversibility

Easy: it's a rule in CLAUDE.md.
