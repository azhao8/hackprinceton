# 0045: Agents ask instead of guessing

- Date: 2026-11-14
- Status: accepted
- Source: collaboration round

When an agent hits a question that could affect the product (decisions, architecture, interfaces between lanes, product details, UI/UX, demo behavior), it stops and asks its human, with the options and a recommendation. The human raises it with the team, and the team decides together. Trivial choices (names, file layout inside a lane, small refactors) don't need asking. The rule lives in CLAUDE.md.
