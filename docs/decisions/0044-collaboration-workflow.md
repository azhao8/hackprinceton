# 0044: How we collaborate day to day

- Date: 2026-11-14
- Status: accepted
- Source: collaboration round

Alex (GitHub azhao8) runs the master agent and is the only one who merges to main. Issues carry a lane label (lane:motion, lane:vision, lane:misc) and an assignee; branches are named `<lane>/<N>-short-name`. Blockers, questions and interface changes go in issue and PR comments; the group chat is for quick pings. The rules live in CLAUDE.md.
